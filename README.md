# Yuno's Cursor

This is a minimal dark themed cursor set created because the windows dark theme cursors are sub par. The original idea was to make cursor files out of the Elementary OS cursors. But, while working on them, it was found that they lacked consistency and did not have some of the cursors that are expected on Windows. Therefore, this set was made from scratch with heavy inspiration from both Windows and Elementary cursors.

# How to install the cursors

Open Windows `Settings`

Navigate to `Accessibility` > `Mouse Pointer and Touch` > `Customize Pointer Image`

Use the `Browse` function for each cursor and point to the location of the cursor files.

This makes it easier to reset the cursors if need be.
